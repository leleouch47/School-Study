## 怎么运行

### 51 单片机（Keil 5）

1. 用 Keil uVision5 打开对应练习目录里的 `.uvprojx` 工程文件
2. 按 `F7` 编译，在 `Objects/` 下生成 `.hex` 文件
3. 用 STC-ISP 之类的工具把 `.hex` 烧录到开发板

> 编译产生的中间文件（`Objects/`、`Listings/`、`*.hex` 等）**没有**提交到本仓库。
> 克隆下来之后需要自己编译一次才能烧录，这是有意为之，避免仓库里塞满二进制垃圾。

### C / C++

```bash
gcc main.c -o main
./main
```

### Python

```bash
python main.py
```

部分练习需要第三方库，会在对应目录的 README 里单独说明安装命令。

## 提交约定
