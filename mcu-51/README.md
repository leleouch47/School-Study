# 51 单片机

单片机课程的实验代码与课后练习。开发环境是 Keil uVision5，芯片是 51 系列。

## 目录约定

每次实验（或每个独立练习）建一个子目录，命名格式：

```
ex01-led-blink/          第 1 次实验：点亮 LED
ex02-key-scan/           第 2 次实验：独立按键扫描
trial-matrix-key/        课后自己练的：矩阵键盘
```

- `ex` 开头 = 课程要求的实验
- `trial-` 开头 = 课后自己练的
- 目录名用英文小写加连字符，避免中文路径在 Keil 里出问题

## 怎么打开

用 Keil uVision5 打开子目录里的 `.uvprojx` 文件（**不是** `.uvoptx`，
后者只存窗口布局，单独打开没有用）。

## 怎么烧录

1. Keil 里按 `F7` 编译，确认 0 Error
2. 在 `Objects/` 目录下找到生成的 `.hex`
3. 打开 STC-ISP，选对芯片型号和串口号，下载

`.hex` 不会提交到本仓库，克隆后请自己编译一次。

## 每个实验子目录里应该有什么

- `main.c`（以及拆分出的其他 `.c` / `.h`）
- `.uvprojx` 工程文件
- 一份简短的 `README.md`：这个实验干什么、接线怎么接、有什么坑

## 接线记录

每个实验的接线方式写在各自子目录的 README 里，格式参考：

| 单片机引脚 | 接到 | 说明 |
| --- | --- | --- |
| P2.0 | LED 阳极 | 低电平点亮 |
