# 其他课程

不属于 `mcu-51` 和 `data-structures` 的零散作业与练习。

这个目录是"暂时没归类"的收容所。**当某个主题在这里攒够 3 个以上练习时，
应该单独提出来开一个新顶层目录**，不要让它无限膨胀下去。

## 目录约定

每个主题一个子目录，命名用英文小写加连字符：

```
python-basics/        Python 基础练习
linux-commands/       Linux 命令练习
course-project-xxx/   某门课的大作业
```

## 每个子目录里应该有

- 代码文件
- 一份 `README.md`：这是哪门课、要解决什么问题、怎么运行
- 如果用了第三方库，写清楚安装命令
