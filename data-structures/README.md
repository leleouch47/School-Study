# 数据结构

数据结构课程的作业与课后实现。语言以 C 为主，部分练习用 Python 写，方便对比。

## 目录约定

```
list/                线性表（顺序表、链表）
stack-queue/         栈与队列
string/              串
tree/                树与二叉树
graph/               图
sort/                排序算法
search/              查找
```

按章节（或按数据结构类型）分目录，不按"第几次作业"分——同一类结构往往要做好几次作业，
放一起更好回顾。

## 文件命名

```
list/seqlist.c           顺序表的实现
list/linkedlist.c        单链表
list/linkedlist_double.c 双向链表
sort/quicksort.c         快速排序
```

同一主题的多个实现放同一目录，文件名体现差异。

## 怎么编译运行

```bash
gcc seqlist.c -o seqlist
./seqlist
```

单文件练习直接编译。如果某个实现拆成了多个文件，会在该目录的 README 里写清楚编译命令。

Python 版本：

```bash
python seqlist.py
```

## 每个实现里应该有

- 完整可编译的代码，不是伪代码片段
- 关键步骤有注释，尤其是指针操作和边界处理
- `main()` 里有测试代码，能直接看到运行结果
- 文件头注释写清楚：时间复杂度、空间复杂度、已知的坑
